# QA Checklist

Run `npm install`, `npm run lint`, `npm run build`, then test all routes and the 404.

Verify navigation, mobile menu, CTAs, phone/email/WhatsApp, form validation/loading/error state, FAQ, blog articles, related articles, sitemap and robots.

Check responsive widths 320–1920px, keyboard/focus behavior, SEO metadata and no horizontal overflow.

Before production lead capture, connect and verify the real contact delivery API.
