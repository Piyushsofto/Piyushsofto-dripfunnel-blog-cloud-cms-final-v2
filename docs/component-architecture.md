# Component Architecture

Shared components: Header, Footer, ContactForm, WhatsAppButton.

Reusable visual patterns: Button, Container, SectionHeading, Hero, TrustBar, ProblemCard, GrowthProcess, ServiceCard, PricingCard, FeatureList, PortfolioCard/framework, BlogCard, FounderCard, FAQ, CTASection, ContactForm, WhatsAppButton, Footer.

Blog content is data-driven in `lib/posts.js`. Navigation is data-driven in `components/Header.js`. Tailwind utilities are available across app/components/lib.
